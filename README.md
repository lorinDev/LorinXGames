# LorinX Games APK

Android 安装包在本仓库的 [Releases](https://github.com/lorinDev/LorinXGames/releases) 页面下载。

当前测试版 APK：[下载 GraffitiMap.apk](https://github.com/lorinDev/LorinXGames/releases/download/v1.0.0-test.1/GraffitiMap.apk)

测试版使用对应 Release 的固定版本链接。正式版发布后，可使用 `releases/latest/download/GraffitiMap.apk` 获取最新正式版。安装包作为 Release 附件发布，不提交到 Git 历史。构建在 Unity 项目中完成，发布由独立 CLI 执行。
